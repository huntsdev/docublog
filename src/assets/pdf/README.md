PDF code blocks use JetBrains Mono Regular v2.304, downloaded from the
[official JetBrains Mono repository](https://github.com/JetBrains/JetBrainsMono/tree/v2.304/fonts/ttf).
The font is distributed under the SIL Open Font License included in `OFL.txt`.
Body text uses the Roboto fonts bundled with the `pdfmake` dependency.

Unicode symbols use [Noto Sans Symbols 2](https://github.com/google/fonts/tree/main/ofl/notosanssymbols2),
and emoji use [Noto Emoji](https://github.com/google/fonts/tree/main/ofl/notoemoji).
Their SIL Open Font Licenses are included alongside the fonts.

`PromptSymbols.ttf` is a 3 KB subset of [Noto Sans KR](https://github.com/google/fonts/tree/main/ofl/notosanskr)
containing space and U+327F, used in the posts' Kali terminal prompts. It was
instantiated at weight 400 and subset with FontTools, then renamed to
`Hunts PDF Prompt Symbols`. Its license is in `PromptSymbols-OFL.txt`.
